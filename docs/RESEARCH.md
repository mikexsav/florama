# Методика и ограничения FLORAMA

## Данные и подготовка

В соревновании одна запись описывает анонимизированный участок и дату. `primary_ndvi` — целевая величина, `is_synthetic_gap` — точки, для которых нужно восстановить значение. Обучение не использует пропущенные целевые значения. Дубли ключа `(anon_polygon_id, date)` запрещены, а прогнозы ограничиваются физически разумным диапазоном NDVI `[-1, 1]`.

## Восстановление NDVI

Базовый прогноз — линейная интерполяция между соседними известными наблюдениями одного участка. Для границ ряда, сезонных пропусков и сложных случаев поверх него обучается `HistGradientBoostingRegressor` на остатках. В признаки входят дата и день года, локальная плотность наблюдений, расстояние до соседних точек, соседняя растительность и согласованные точки других участков. При расчёте признаков конкретный искусственный пропуск всегда скрыт, поэтому нет утечки target.

Базовое обучение использует шесть масок по 15% известных точек. Значение 15% соответствует доле контрольных точек среди наблюдавшихся значений в предоставленном test: 2323 / (13164 + 2323). Доля от всех строк файла составляет около 4,7%.

Расширенная модель обучает отдельные поправки для Sentinel-2, Landsat и MODIS. Классификатор оценивает вероятность источника по видимым наблюдениям, календарю пролётов и расстояниям до соседних снимков. Итог смешивает общий прогноз и прогноз спутниковых экспертов. Смещения между сенсорами оцениваются по совпадающим видимым датам одного поля и сезона.

`benchmark_sources.py` сравнивает рецепты на одинаковых контрольных точках: 39 участков делятся на четыре непересекающиеся группы с seed 20260905. Контрольные участки полностью исключены из обучающих признаков; маски проверки имеют отдельные seeds 9001–9004. Для обучения используются seeds 142, 243, 344, 445, 546, 647. Итоговый RMSE вычисляется по объединённым ошибкам, а не средним RMSE групп. Выбор веса по этой проверке означает, что она является валидацией для выбора модели; независимый результат платформы считается отдельно.

Приватный ground truth не используется для обучения и выбора модели. `ndvi_zscore`, `status` и готовая климатология исключены из признаков. Даты переводятся в дни явно при вычислении новых временных расстояний, независимо от единиц хранения datetime в pandas.

Формула локального пересчёта баллов: `GapScore = 30 * max(0, 1 - RMSE / 0.10)`. Целевой RMSE 0.02 соответствует 24 баллам; достижение этого порога подтверждается только независимой проверкой.

## Адаптация к входному файлу

Модель v16 сохраняет общую модель v15 и добавляет адаптацию на видимых значениях входного test. В адаптацию передаются дополнительные маски с seeds 771, 882, 993, 1104, 1215, 1326; вес этих примеров равен 3. Идентификатор поля используется как категориальный признак. Финальный прогноз — равная смесь общей и адаптированной моделей, внутри каждой используется равная смесь общей регрессии и спутниковых экспертов.

Все контрольные строки скрыты навсегда до построения примеров адаптации. Для новых масок эти значения недоступны. Адаптированная часть включается только при точном совпадении SHA-256 исходного CSV, иначе применяется общая модель. Такой контроль не позволяет переносить обученные на видимых значениях настройки на другой файл с другими скрытыми строками.

На 4636 точках четырёх групп локальный RMSE уменьшился с 0.0634758 до 0.0625576. Это результат выбора модели на train, не оценка платформы. Он не подтверждает достижение целевого RMSE 0.02.

## Спектральный анализ

Для пользовательских полигонов сервер читает Sentinel-2 L2A COG. Используются B02/B04/B05/B08/B8A/B11/B12 и SCL. Пиксели облаков, теней и иных невалидных классов исключаются до агрегации. Отражательная способность B08 (NIR), B11/B12 (SWIR) используется в формулах:

- `NDVI = (B08 - B04) / (B08 + B04)` — фотосинтетически активная растительность;
- `NDMI = (B08 - B11) / (B08 + B11)` — влагосостояние кроны;
- `NDRE = (B8A - B05) / (B8A + B05)` — чувствителен к хлорофиллу;
- `BSI = ((B11+B04)-(B08+B02))/((B11+B04)+(B08+B02))` — индикатор открытой/сухой поверхности;
- EVI и соотношение SWIR/NIR — дополнительные индикаторы.

То есть листва различается именно по ИК-отражению; RGB не является основанием решения.

## Риски и объяснения

Для каждой даты строится сезонная норма по тому же окну дней года за предыдущие два года. При достаточном контексте низкое z-отклонение NDVI образует предупреждение. Метеоархив ERA5 привязывается к этой же дате: накопленные осадки и средняя температура включаются в объяснение.

Риск «больной растительности» — скрининговый сигнал по сочетанию падения NDVI/NDRE, влаги и облачности. Он не является фитопатологическим диагнозом. «Состав почвы по ИК» в интерфейсе корректно назван спектральным индикатором BSI/SWIR: лабораторный химический состав по Sentinel-2 не определяется.

## Воспроизводимость и источники

Модель и метрики хранятся в `backend/models/`; запуск указан в README. Реальные провайдеры кэшируются в БД, а не подменяются заглушками при ошибке. Данные Sentinel берутся из Earth Search STAC, погода — Open-Meteo Historical/ERA5, поиск — OpenStreetMap. Для кадастрового номера есть переход к НСПД и импорт границы пользователем.
